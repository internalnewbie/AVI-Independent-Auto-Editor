# Security and privacy

This is an experimental local-first video editor; do not expose its local Ollama API to public networks. Review external downloads and third-party licenses before enabling them. Never commit tokens, private keys, personally identifiable data, narration files, footage, caches or logs. If reporting an issue, redact paths, names, URLs and any personal data from diagnostic files.

For security concerns, contact the repository owner privately rather than posting secrets in a public issue.
